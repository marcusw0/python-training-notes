# Novice Python Foundations

This course section introduces Python fundamentals through Jupyter notebooks.
The examples favor small, focused cells with output shown directly below the
code that produced it.

## Topic Map

| Topic | Files | Main ideas |
| --- | --- | --- |
| Python basics | `py-beginner.ipynb` | Data types, strings, formatting, comprehensions |
| Variables and operators | `function-variables-operators.ipynb`, `calculations.ipynb` | Built-ins, assignment, arithmetic, booleans |
| Conditional logic | `conditions.ipynb`, `if_statements.ipynb` | Comparisons, logical operators, branching |
| Loops | `for_loops.ipynb`, `while_loops.ipynb` | Iteration, ranges, nesting, break, continue |

| Recursion and modules | `recursion.ipynb`, `modules.ipynb` | Recursive calls, imports, standard library modules |

## Practice Labs

1. Write a calculator cell that computes monthly savings from salary, rent, and
   food costs.
2. Add a conditional that classifies a score as passing or failing.
3. Build a multiplication table with nested loops.
4. Create a list of favorite foods, then append, remove, sort, and slice it.
5. Convert a list of key-value pairs into a dictionary and update one value.
6. Write a function that returns the largest number in a list.
7. Use `*args` to write a function that adds any number of inputs.
8. Use `filter()` with a lambda to keep only even numbers.
9. Create a closure that remembers a greeting prefix.
10. Write a generator that yields the first ten multiples of three.

## Quick Reference

| Pattern | Example |
| --- | --- |
| Print output | `print("Hello")` |
| Conditional branch | `if score >= 70:` |
| For loop | `for item in items:` |
| While loop | `while count < limit:` |
| Function | `def add(a, b): return a + b` |
| Lambda | `lambda x: x * x` |
| Generator | `yield value` |

## Notes for Learners

The notebooks are intentionally small and repetitive. Run each cell, inspect
the output, then change one value at a time to see how Python responds.
