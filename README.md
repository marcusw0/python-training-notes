# Python Training Notes

A collection of Python notes, examples, and exercises for learning Python at
your own pace.

## Contents

- `1-novice/` — Python basics, collections, loops, functions, and modules
- `2-apprentice/` — Classes, file handling, command-line arguments, virtual
  environments, data structures, and algorithms
- `3-journeyman/` — Python testing examples using `unittest`

Most lessons are Jupyter notebooks and can be run one cell at a time.

## Getting Started

Make sure Python 3 and Jupyter are installed, then start Jupyter from this
folder:

```bash
python -m pip install jupyter
jupyter lab
```

Open a notebook and work through the folders in order. Some sections include
their own README with a suggested learning path.
